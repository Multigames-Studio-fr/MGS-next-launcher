# Notes de version (v3.2.0 → v3.3.7)

Merci d'avoir utilisé le launcher 

Nouveautés importantes

- Mode hors-ligne
  - Si vous êtes hors-ligne et que vous avez déjà sélectionné un compte local, le launcher peut maintenant démarrer le jeu sans connexion. Utile quand vous n'avez pas Internet ou que l'authentification en ligne échoue.

- Correction automatique des packs de ressources
  - Le launcher détecte maintenant plusieurs erreurs courantes liées aux packs de ressources et applique automatiquement des actions correctives (nettoyage des caches et réparations simples) pour éviter que le jeu ne plante au démarrage.

Améliorations visibles pour l'utilisateur

- Meilleure gestion des erreurs
  - Les fenêtres d'erreur et overlays sont plus fiables : vous pouvez fermer les popups manuellement (bouton ou touche Escape) et l'interface ne devrait plus se bloquer sur des erreurs d'affichage.

- Mises à jour plus robustes sous Windows
  - Les mises à jour ont été durcies pour éviter des problèmes de permissions sur Windows. Le launcher gère mieux les chemins et peut fermer proprement la fenêtre de mise à jour si nécessaire.

Corrections et petits plus

- Divers bugs UI corrigés (moins de crashs liés aux éléments manquants dans l'interface).
- Améliorations de stabilité lors du lancement et meilleure surveillance des logs pour détecter les problèmes.
- Quelques petites améliorations visuelles et CSS pour une expérience plus cohérente.

Conseils pour l'utilisation

- Si votre lancement échoue et que vous êtes hors-ligne : sélectionnez d'abord un compte local dans les paramètres, puis relancez le jeu — le mode hors-ligne s'enclenchera automatiquement.
- Si le jeu indique un problème avec un pack de ressources, laissez le launcher tenter la réparation automatique, puis réessayez de lancer le jeu.

Version courte à afficher dans la page de release

v3.3.7 — Mode hors-ligne, corrections automatiques des packs de ressources, améliorations de la robustesse et correctifs Windows.
